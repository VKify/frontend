# HTML wallpapers in VKify

Each wallpaper is a standalone HTML page with its scripts and assets.

1. Create `web/<wallpaper-slug>/index.html` and the animation scripts.
2. Make the animation resize with the window.
3. Add its record (`id`, `src`, preview and metadata) to `src/data/wallpapers.js`.
4. Publish the folder and use the direct HTML URL in VKify.
